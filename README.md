# Bate Lata

Aplicação web desenvolvida como projeto acadêmico com o objetivo de apresentar a ONG fictícia Bate Lata, iniciativa voltada à inclusão social de crianças por meio da música, da percussão e do reaproveitamento de materiais.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git e GitHub

## Funcionalidades

- Navegação no formato SPA
- Menu responsivo
- Página de apresentação da ONG
- Exibição dos projetos sociais
- Modal com informações de participação
- Formulário de cadastro
- Validação dos campos
- Máscaras para CPF, telefone e CEP
- Persistência de dados com LocalStorage

## Estrutura do projeto

O projeto está organizado em diretórios separados para arquivos HTML, CSS, JavaScript e imagens, facilitando a manutenção e a separação de responsabilidades.

## Versionamento

O versionamento do projeto utiliza Git e segue uma estrutura baseada no GitFlow, com as branches `main`, `develop` e `feature/`.
